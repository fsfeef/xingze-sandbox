## 0. 先记死的三条

1. **作者自己说的精度**：数据全部来源于网络公开数据、**完全不准确且精度非常低，仅供演示参考**。我们也一样诚实标：楼高是推算的就标推算（层数×3.2 + OSM 标签），模拟数据标模拟，估算标估算，不许把推算包装成真实。
2. **没有代码仓库和开源许可**：他没有给代码仓库和开源许可，**我们只学方法，不碰他的代码**。评论区那个 GitHub CityBox 是另一个评论者自己的项目，别混了，别去抄。
3. **楼高口径**：方法照抄（推算 + 校准），但 **CNBH / CMAB 不当源**——CNBH 全城最高仅约 40m（339 塔读 32m）、科研许可，CMAB 压高楼；之前已撤回。我们楼高还是**层数×3.2 + OSM 标签**（OSM 有 height 标签的楼拿标签校准）。
4. **比例错的要修对，不能把他的错也搬过来**（14:11 林萧补）：他那个里面有些比例不对，照抄时比例错的地方要修对。339 塔就是一例——他标签写 339m、模型只有 113m 级，我们修好 339m 才算超过。建筑、铁路、树、路、桥都照着他那个弄，但凡比例不对的都先修对再搬。

## 3. 学习清单四样（13:50 林萧补，每样：他是怎么做 / 我们怎么学 / 改完长什么样）

### 3.1 楼顶

- **他是怎么做**：屋顶形态 + 屋面颜色取自 Sentinel-2 卫星影像 + gpt-image 生成屋面样张做无缝贴图；楼顶有处理（生成贴图/插画 + 屋顶形态），远看成片有变化；近看作者自己承认不行（“只能远观，不可细看”）。
- **我们怎么学**：只学“屋顶要分形态、屋面要分颜色、顶面和立面要区分开”这个做法，不抄他的贴图和颜色。按我们自己的高度（层数×3.2 + OSM 标签）、我们的游戏画面风格做。动手前先对着参考站截图看清楚：哪里用深色砖、哪里用青瓦，写成配色表再动手（14:03 林萧要的细节，A 路出配色表）。体形一并改（13:48/13:49）：我们现在的楼都是方块圆柱，照着他那个一栋一栋改——退台、坡顶、幕墙、转角、裙楼，圆角还是棱角都照他的图，不再做成方块圆柱体。
- **改完长什么样**：全部楼顶面按高度带/分区重新着色（顶面冷蓝紫，与立面一眼区分）；顶面边沿加女儿墙线（带霓虹细线）；按种子确定性分型——高层退台顶、中层坡顶/四坡顶、低层平顶 + 屋顶机房盒子；高层顶有发光边。近景抽查 20 栋 100% 有房顶处理，25 地标 100% 独立屋顶造型（A 路验收）。
- **归属**：A 路 `app/roofs.js`；B 路对标卡里逐栋记屋顶差在哪。

### 3.2 车

- **他是怎么做**：车流是简易方块小车，沿路跑；实测街面评价是“车是简易方块小车”。
- **我们怎么学**：只学“主干道上有车沿路跑、夜里开车灯”这个做法，不学方块造型。我们的车按现实车型做（轿车/SUV/公交等），无标无牌（13:54 林萧再定：车一定要做真的、能开的，不要做简易方块车），要高级；车型、颜色各不相同，不许重复。
- **改完长什么样**：主干道上 8–12 辆车沿路跑（位置按路网走，不穿楼），车型不重复，夜里有车灯；玩家能开车（上限 120 km/h，已有），开车有车内第一人称视角（已有）。主干道截图里 ≥3 辆车在跑（C 路验收）。
- **归属**：C 路 `app/roads.js`（车流）；开车模式已有，保住。

### 3.3 路灯

- **他是怎么做**：路灯按街道间距、位置摆放，夜里亮灯（参考站夜景里路灯是亮的，做法是“沿路摆、夜里亮”）。
- **我们怎么学**：学他的摆放方法（间距、位置、亮灯），不抄具体灯型。我们的灯是实灯：包里 **141,756 盏**真实灯位（不是程序造的假灯），按他的方法摆出来——沿主干道/次干道间隔摆，同条街成排，夜里全亮。
- **改完长什么样**：夜景里所有路灯都要亮着（老规矩）；夜景走路截图里至少 5 盏灯可见，灯光暖黄 + 霓虹青两档；白天不亮。路灯只在包里是线（不亮）是现在的短板，F 路亮化后验。
- **归属**：F 路 `app/street.js`（路灯亮化）。

### 3.4 道路

- **他是怎么做**：OSM 路按等级上色加粗细、带宽面；分级上色、标线、斑马线、人行道；路在总览里看得见，近景有标线。
- **我们怎么学**：学他的做法（分级上色、标线、斑马线、人行道），颜色和画法是我们自己的游戏画面风格，不许一眼看出来是照搬。动手前先对着参考站截图看清楚路到底是怎么画的（14:03 林萧要的细节：哪里该怎么弄都看清楚了再画）。
- **改完长什么样**：主干深蓝沥青、次干中蓝灰、步道浅灰蓝，三档拉开对比，总览截图路网可认；主干/次干中心虚线 + 边线（冷白，主干中心线荧光黄）；抽查 10 个主干路口 100% 有斑马线；主干两侧加人行道带；主干道交叉口立通用路名牌（星泽市虚构路名，0 真名）；下雨时路面反光增强。道路是头号任务（13:47：所有道路看不见）——先让路看得见，再谈别的。
- **归属**：C 路 `app/roads.js`。
